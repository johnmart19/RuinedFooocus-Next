# Tool index

Use the existing checkout interpreter: `venv/Scripts/python.exe` on Windows or
`venv/bin/python` on Linux/WSL. Shell examples require POSIX `sh` and set
`RF_PYTHON` to that interpreter. Source support is separate from execution
qualification. See the [tool contracts](../docs/integrations/tools.md) for API
login, cancellation, pins, fixtures and the checks performed.

Each row identifies a real consumer. A manually invoked acceptance adapter is
maintained even when production code never imports it. Dedicated video adapters
and recipe helpers were removed with the image/Chat scope cleanup. `--help` is read only; helper modules without a CLI are import only.

Dependency groups: **S** = Python standard library; **R** = pure bundled registry
reader; **G** = installed Gradio/client; **M** = NumPy/Pillow/PyAV; **H** =
requests/filelock/Hub download closure; **N** = pinned ComfyUI/GGUF and matching
Torch/runtime; **T** = Transformers/tokenizers/sentencepiece; **F** = Git, Ruff,
Node and Prettier. Install/runtime eligibility remains owned by
`ruinedfooocus/packaging/`; these tools do not install dependencies.

All paths below are relative to this directory. Validation filenames are in
`tests/` and run through `check_cpu.py`. Heavy inference commands need a separate
explicit workload scope; this tool pass ran no video, model or GPU workloads.

Feature replay reuses at most 4096 successfully applied exact ordered SHA prefixes
inside one invocation's isolated repository. Every selected feature still runs
its own Python/resource contracts and requested CPU tests; the JSON retains its
full source commit list. Failed steps are never cached. Failures print their
concise cause immediately, with the complete error retained in the JSON report.
An isolated closure reports unresolved function-body integration imports in
`deferred_imports`; eager imports and bundled resources remain strict. The full
candidate requires a separate strict `python_contracts` audit. Native fixture
revisions can be declared by feature metadata before bootstrap exists and must
match bootstrap whenever it is present; no mutable vendor HEAD is a fallback.
